### HIPPIE at a Glance

* **HIPPIE** stands for *High‑dimensional Interpretation of Physiological Patterns In Extracellular recordings*. It's a multimodal, deep learning architecture combining **self‑supervised pre‑training** with **supervised fine‑tuning** to classify and cluster neurons based on electrophysiological signals.

* The model is built around **conditional convolutional joint autoencoders**—more specifically, **parallel conditional VAEs (cVAEs)**—that process two key data modalities: the **average spike waveform** and the **interspike interval (ISI) distribution**, while conditioning on experimental technology type.

---

### Inputs, Architecture & Training

* **Inputs**:

  * **Waveform**: 2.5 ms average action potential per neuron (\~50 data points at 20 kHz; averaged over 100–500 spikes).
  * **ISI distribution**: Time between spikes, binned over \~100 ms in 1 ms bins.
  * **Recording technology**: Categorical metadata (e.g., probe type) used as a conditional variable.

* **Model**:

  * Each modality is handled by a **1D ResNet-based cVAE encoder and decoder**.
  * Encoded latents from waveform & ISI are merged via an **MLP “mixture module”**, followed by decoders to reconstruct both modalities.

* **Training Strategy**:

  * **Self‑supervised pre‑training** over unlabeled datasets using a **leave‑one‑dataset‑out** approach for generalization.
  * **Supervised fine‑tuning** on labeled data (80% train / 20% test), evaluated primarily with KNN probes for classification accuracy.

### Results & Highlights

* **Cell‑type discrimination** and **anatomical classification** both **outperformed other unsupervised methods**, showing strong alignment with known neuron types and brain regions across both in vivo and in vitro datasets.

* The learned **latent space is interpretable**, organizing neurons along electrophysiological gradients and effectively correcting for batch effects across diverse experimental setups.

## Conceptual flow (pipeline)

* Inputs

  * Spike-sorted units → mean waveform (2.5 ms window) + ISI histogram + recording tech as covariate (per project description). 
* Model

  * Two 1D encoders/decoders (waveform / ISI) → fused latent via MLP mixture → β-VAE loss; Lightning training loops; probes (KNN and optionally MLP) for downstream tasks. 
* Modes

  * Pretrain (self-supervised / covariate-aware), fine-tune (supervised), supervised probe; logging via Weights & Biases (flags in README). 
* Outputs

  * `.ckpt` files for each modality; CSV embeddings for eval/inference.

## How to use (practical)

* Install & env

  * Clone → create py3.10 env → `pip install .` (deps above). 
* Train

  * Drop dataset folder under `/datasets`, then run the provided training command with your preferred hyperparams (e.g., `--z_dim 10`, `--beta 0.5`, batch/splits). 
* Inference / embeddings

  * Run `inference_from_trained_model.py` with checkpoints to export embeddings.
